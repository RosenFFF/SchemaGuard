# Data Card

## Data Usage and Privacy
- All example data used in tests and documentation is fictitious.
- No real PII (Personally Identifiable Information) is used.
- Test email domains use `example.invalid` or similar safe domains.

## Synthetic Benchmark
> **Note**: This repository is a synthetic benchmark created for evaluating RepoCare.

## Supported Formats
- CSV: Comma-separated values.
- JSON: JavaScript Object Notation.

## Privacy Considerations
SchemaGuard is designed to help detect and redact PII, but it is not infallible. Users should exercise caution and not rely solely on this tool for regulatory compliance without human review.
