# Security Policy

## Supported Versions
Only the latest major version is currently supported with security updates.

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.
Instead, report them privately.

## Security Boundaries
SchemaGuard is a local CLI tool. It does not provide any network access and does not connect to remote servers. It is not designed to be a complete compliance scanner.

## Privacy Note
SchemaGuard does not process real PII in tests. All tests must use fictitious samples.
